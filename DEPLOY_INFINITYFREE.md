# Деплой на InfinityFree (dash.infinityfree.com)

Сервис «Сладкие сны» — PHP + MySQL. Ниже пошаговая инструкция
развёртывания на бесплатном хостинге InfinityFree.

Пользователь InfinityFree: **San4eZ1**

## 1. Создать базу данных MySQL

1. Зайдите в панель `https://dash.infinityfree.com` под San4eZ1.
2. Слева выберите **MySQL Databases**.
3. Нажмите **Create Database**, придумайте имя (например `hotel`)
   и пароль. Система покажет итоговые реквизиты:
   - Хост (Host), обычно `sql1XX.infinityfree.com`
   - Имя базы (обычно с префиксом аккаунта, например `if0_XXXXXXX_hotel`)
   - Имя пользователя (обычно `if0_XXXXXXX`)
   - Пароль
4. Запишите эти 4 значения — они понадобятся в шаге 4.

## 2. Импортировать таблицы и данные

1. Откройте **phpMyAdmin** — кнопка **phpMyAdmin** в разделе
   **MySQL Databases**.
2. В списке слева выберите созданную базу.
3. Перейдите на вкладку **Импорт** и поочерёдно загрузите:
   - `site/schema.sql`
   - `site/seed.sql`
4. Нажмите **ОК**. В базе появятся таблицы `rooms`, `bookings`, `admins`
   и 6 номеров.

## 3. Загрузить файлы сайта

Вариант A (рекомендуется) — FTP через **File Manager** в панели:

1. В разделе **Accounts → Manage** выберите свою учётную запись.
2. Нажмите **File Manager** — откроется файловый менеджер.
3. Удалите содержимое папки `htdocs` (корень сайта), если там что-то есть.
4. Загрузите содержимое папки `site/` в `htdocs`, сохранив структуру:
   - `index.php`, `catalog.php`, `booking.php`, `login.php`, `logout.php`
   - `admin/index.php`
   - `lib/`, `assets/`
   - (не загружайте `schema.sql` / `seed.sql` в веб-корень)

## 4. Настроить подключение к базе

Вариант A — переменные окружения через `.htaccess`:

1. В корень сайта (`htdocs`) создайте файл `.htaccess` со строками:

```
SetEnv DB_HOST sql1XX.infinityfree.com
SetEnv DB_NAME if0_XXXXXXX_hotel
SetEnv DB_USER if0_XXXXXXX
SetEnv DB_PASS ПАРОЛЬ_ОТ_БАЗЫ
```

Вариант B — напрямую в `lib/config.php`:

1. Откройте `site/lib/config.php`.
2. Впишите реальные значения в `$dbHost`, `$dbName`, `$dbUser`, `$dbPass`.

> Не загружайте `.htaccess` с настоящим паролем в GitHub-репозиторий.
> Образец — в файле `site/htaccess.example`.

## 5. Проверить работу

- Откройте сайт: `https://ВАШ-ДОМЕН.infinityfreeapp.com/`
- Адрес вы увидите в панели в разделе **Accounts**.
- Проверьте: главную, каталог с фильтрами, бронирование (слайдер картинок,
  маска телефона), вход администратора.

**Вход администратора:** логин `hotel123`, пароль `adminHotel`.

## Переключение тем

В правой части шапки сайта есть переключатель:
- **Тёмная тема** (киберпанк-стиль, с эффектами) — по умолчанию;
- **Светлая тема** (чистая, без эффектов).
Выбор сохраняется в cookie и запоминается между страницами.

## Возможные проблемы

- **Ошибка подключения к БД** — проверьте хост/имя/пользователя/пароль
  в шаге 4. У InfinityFree хост не `localhost`.
- **401/404 на страницах** — убедитесь, что файлы лежат в `htdocs`
  (не в подпапке).
- **Слайдер/картинки не грузятся** — проверьте папку `assets/img/`
  и что в `seed.sql` указаны относительные пути `assets/img/...`.
